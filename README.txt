LOST & FIND — CAMPUS RECOVERY PORTAL
College Mini Project | Web Design

PROJECT OVERVIEW
Lost & Find is a campus lost-and-found website concept that helps students report lost belongings, share found items, and browse listings.

HOW TO RUN
1. Extract the ZIP file.
2. Open the Lost_and_Find_Mini_Project folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.
4. Internet is needed for the Google Fonts used in the design. The website still works without them.

FEATURES
- Professional, responsive landing page
- Search by item name, description, category, and location
- Filter listings by Lost / Found
- Filter by category
- Add a lost/found report through a modal form
- New reports appear in the current browser session
- Mobile-friendly navigation
- Demo sample listings

IMPORTANT LIMITATION
This is a front-end mini-project prototype. New reports are held in JavaScript memory and disappear after refreshing the page. The contact email is displayed as part of the demo description. There is no real database, login, or backend yet.

NEXT STEP FOR A FULL PROJECT
Add a backend (for example Node.js + Express), a database (MySQL or MongoDB), secure user authentication, image uploads, admin moderation, and a safe contact/claim workflow. Never publish sensitive student details publicly.
